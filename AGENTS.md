# Persistent Project Rules & Instructions

- **APK Generation Directive**: Always run `gradle assembleDebug` on every large build update or major milestone so that the compiled APK in `app/build/outputs/apk/debug/` is kept up-to-date for testing, streaming emulator installations, and exports.
- **Protocol Standards**: Keep all outgoing cellular SMS messages formatted in clear, human-readable natural language prompts with embedded JSON schemas for AI compatibility.
